# IT Help Desk

A web-based IT Help Desk application built with Python, Flask, SQLite, HTML, and CSS.

## Features

* User registration and login
* Password hashing
* User sessions
* Create and track support tickets
* Ticket status updates
* Support staff role
* Support staff can view all tickets
* Support staff can send messages to users
* SQLite database for users and tickets
* Custom CSS styling and fonts
